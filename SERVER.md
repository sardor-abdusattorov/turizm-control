# Требования к серверу — Turizm Control

Сервер под Docker-стек (Laravel + PostgreSQL + Nginx + OnlyOffice).

## Конфигурация железа

| Компонент | Минимум | Рекомендуется |
|-----------|---------|---------------|
| **CPU**   | 4 ядра  | 6 ядер        |
| **RAM**   | 8 GB DDR4 | 16 GB DDR4  |
| **Диск**  | 120 GB SSD | 256 GB SSD (NVMe) |
| **Сеть**  | 100 Mbit | 1 Gbit       |

> Диск **только SSD** — на HDD PostgreSQL и OnlyOffice будут тормозить.

## Софт

- **ОС:** Ubuntu Server 24.04 LTS (без графики)
- **Docker + Docker Compose** — стек поднимается командой `docker compose up -d`

## Важно

- **8 GB** хватает для небольшой команды (до ~5–10 человек). Слабое место — **OnlyOffice** под одновременным редактированием документов: при росте нагрузки доткнуть RAM до **16 GB**.
- **UPS (ИБП)** — защита БД от внезапного отключения питания.
- **Бэкапы:** дамп PostgreSQL (`pg_dump`) + папка `storage/` по расписанию на внешний носитель.
- **HTTPS** обязателен (OnlyOffice корректно работает только по https).
